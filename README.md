# Trip Atlas · 여행 수첩

여행 **일정 · 지도 · 가계부 · 기록**을 여행별로 한 곳에서 관리하는 개인용 웹앱입니다.
[shizuoka-trip-2026](https://github.com/jwdev1995/shizuoka-trip-2026) 한 번의 여행용 페이지에서 출발해, 앞으로의 모든 여행을 같은 페이지에서 다루도록 다시 만들었습니다.

## 할 수 있는 것

| 탭 | 내용 |
|---|---|
| **내 여행** | 여행 목록(예정 / 진행 중 / 다녀옴), 커버 사진, D-day, 예산 대비 지출 바 |
| **개요** | 커버 사진, 한 줄 소개, 일자별 요약, 사진 모음, 준비 체크리스트, 예산, 장소 분류, 진행 현황 |
| **일정** | 날짜별 타임라인. 시각·장소·사진·메모·이동수단, 순서 바꾸기, 방문 완료 ✓ / 건너뜀 ⊘, **구글 지도 경로 열기**(그날 정류 전부 경유지로), 텍스트 복사 |
| **지도** | Leaflet 지도에 번호 핀 + 일자 경로선, 일자 필터, 내 위치, 장소 검색, 장소 사진(목록·팝업), **위키백과 사진 일괄 찾기**, **구글 지도에서 열기 / 길찾기**, **KML 내보내기**(구글 내 지도에 가져오기), CSV |
| **가계부** | 빠른 입력(금액 + 분류 칩), 상세 입력(통화·결제수단·장소·계획/실제), 예산 진행률, 분류별·일자별·결제수단별 집계, 환율 직접 입력 / 오늘 환율 가져오기, CSV |
| **기록** | 일자별 일기 + 별점(자동 저장), **날짜별 사진 올리기**(설명·크게 보기), 방문/건너뜀 장소 요약, 여행 회고 통계(방문 수, 지출, 계획 대비, 최대 지출), 총평 |
| **백업·설정** | JSON 내보내기 / 불러오기(병합·교체, 올린 사진 포함), 예시 여행 불러오기, 구글 지도 API 키, **디자인 버전**, 테마, 초기화 |

### 구글 지도 연동 (지난 여행에서 아쉬웠던 부분)

- 장소마다 **현지어 이름 + 좌표**로 구글 지도를 열어 엉뚱한 곳이 뜨는 문제를 줄였습니다.
- 장소 추가 시 **구글 지도 URL을 붙여넣으면 좌표를 자동으로** 읽습니다 (`@lat,lng`, `!3d..!4d..`, `query=lat,lng` 모두 지원). 짧은 `maps.app.goo.gl` 링크는 좌표가 없으니 긴 주소를 쓰거나 OpenStreetMap 검색을 이용하세요.
- **KML 내보내기** → [구글 내 지도](https://www.google.com/maps/d/) 가져오기 → 구글 지도 앱 "저장됨 › 지도"에서 날짜별 레이어로 전부 확인할 수 있습니다.
- 일정 탭의 **구글 지도 경로** 버튼은 그날의 모든 정류를 경유지로 넣은 길찾기를 엽니다 (경유지 최대 9개).

### 사진

- **커버 사진**(여행 정보 수정)과 **장소 사진**(장소 수정)은 세 가지 방법으로 넣습니다: 기기에서 올리기, 이미지 URL, **위키백과에서 찾기**(문서 대표 사진을 미리 보고 선택. 출처 링크가 함께 저장됩니다).
- 지도 탭의 **사진 찾기**는 사진이 없는 장소를 한 번에 검색합니다. 식당·카페·상점은 엉뚱한 문서가 걸리기 쉬워 기본으로 꺼져 있고, 문서 제목이 장소 이름과 다르면 "확인 필요"로 표시합니다.
- **기록 탭**에서는 날짜별로 찍은 사진을 여러 장 올립니다. 올린 사진은 긴 변 1600px(썸네일 480px) JPEG로 줄여 브라우저 IndexedDB에 저장하고, 백업 JSON에 함께 들어갑니다.
- 위키백과 검색은 일본어 → 영어(현지어 이름), 한국어 → 영어(한글 이름) 순으로 시도하며, 지도·국기 같은 SVG는 제외합니다.

### 디자인 버전 (스킨)

같은 데이터를 네 가지 모습으로 봅니다. 상단의 ◧ 버튼, 백업·설정의 "디자인 버전" 카드, 또는 주소 뒤 `?skin=…`으로 바꿉니다. 라이트·다크 모두 지원하며 `styles/skins.css` 한 파일이 `html[data-skin]`에 따라 기본 CSS를 덮어씁니다.

| 버전 | `?skin=` | 참고한 것 | 특징 |
|---|---|---|---|
| 괘선 (기본) | `default` | — | 괘선과 여백으로만 나누는 도구형 화면 |
| 노션 | `notion` | 노션 여행 플래너 템플릿 | 전폭 커버 + 큰 아이콘, 속성 표(📍📅🏷👥), 갤러리 뷰 카드, 💡 콜아웃, 노션 태그 색 |
| 저니 | `journey` | Wanderlog · TREK · Airbnb | 둥근 카드와 그림자, 사진 히어로에 겹친 헤더, 알약 탭, 떠 있는 하단 탭 |
| 에디토리얼 | `editorial` | Kinfolk · Cereal · Monocle | 세리프 제목(Playfair Display · Noto Serif KR), 이중 괘선, 목차형 목록, 드롭캡 |

## pintrip · 모바일 여행 앱 (`pin/`)

`/pin/` 은 같은 데이터를 쓰는 **모바일 앱형 화면**입니다. 국내 여행 앱 '록핀'(App Store, 코르딕스)의 기능 구성과 화면 흐름을 벤치마킹해 자체 브랜드·자체 코드로 만들었습니다. 로고·이름·제휴 브랜드는 가져오지 않았습니다.

| 하단 탭 / 메뉴 | 내용 |
|---|---|
| **홈** | 여행·특가 배너 캐러셀, 퀵메뉴 8개, 지역 선택(전체·일본·동남아·중화권·국내), 다가오는 여행 D-day, 급락 항공·주변 맛집 TOP·저장한 핫플·가이드 |
| **일정** | 여행 목록 → 지도 동선(번호 핀), Day 탭, **손잡이를 끌어 순서 바꾸기**, 장소 사이 이동 시간·거리 어림, **장소에서 바로 비용 추가**, 동행 초대·**공유 링크**(서버 없이 링크에 일정을 압축해 전달) |
| **가계부·정산** | 현지 통화 입력 → 원화 자동 환산, 예산 대비 실시간 잔액, 결제한 사람·나눌 사람 지정, **N분의 1 정산**(최소 송금 횟수로 누가 누구에게 보낼지), 분류별 집계, 정산 내용 복사 |
| **AI 챗** | 기기 안에서 동작하는 규칙 기반 도우미: 오늘·내일·N일차 일정, 남은 예산, 정산, 환율, 분류별 추천, 항공 특가 |
| **내 주변** | 시즈오카(시내·시미즈·후지) 30곳 + 도쿄 10개 구역(신주쿠·시부야·에비스·롯폰기·이케부쿠로·긴자·도쿄역·츠키지·아사쿠사·아키하바라) 70곳. 지역·구역 선택, 食べログ(점수·리뷰 수)/Google(구역별 실시간 별점·리뷰 수) 탭, 상세 시트에 가게 소개 유튜브 영상·인스타그램 해시태그 링크, 타베로그 점수 핀, 가게를 소개한 유튜브 영상, 인스타그램 해시태그, 맛집·카페·3.5+·유튜브 필터, 거리순/점수순, 일정·콘텐츠에 추가 (`pin/js/eats.js`, 2026-11-06 확인) |
| **콘텐츠** | 인스타그램·유튜브·블로그·지도 링크로 **SNS 핫플 저장**, 폴더·분류·해시태그, 장소 탭에서 모아 보고 **일정에 바로 추가** |
| 급락 항공 / 숙소 알림 / 내 정보 / 알림 | 할인율 표시 항공 검색·정렬·일정 만들기, 숙소 **목표가 알림**과 **가격 그래프**(최고·현재·최저가), 이름·지도 설정·백업 메뉴, 알림함 |

- 여행·장소·일정·지출은 Trip Atlas 저장소(`trip-atlas:v1`)를 **그대로 공유**합니다. 지출에는 `payer`(결제한 사람)와 `split`(나눌 사람, 비어 있으면 전원) 필드가, 여행에는 `members`가 더해집니다.
- pintrip 전용 상태(콘텐츠·가격 알림·채팅)는 `localStorage`의 `pintrip:v1`에 저장됩니다.
- **항공·숙소는 실제 판매처와 연결되지 않은 샘플 데이터**이며(`pin/js/data.js`), 화면에도 "샘플"로 표시합니다. 실제 서비스로 쓰려면 이 파일을 판매처 API 호출로 바꾸면 됩니다.
- 배포 사이트(`ljw-dev-git.github.io`)에서는 `pin/js/mapkit.js`의 기본 키로 **구글 지도**를 보여 줍니다. 이 키는 Maps JavaScript API 전용, 이 사이트 리퍼러 전용이며 하루 지도 로드 300회(월 무료 10,000회 이내) 할당량이 걸려 있습니다. 다른 호스트에서는 OpenStreetMap이 기본이고, **멤버십 → 지도 설정**에 구글 지도 API 키를 넣으면 일정·내 주변 지도가 구글 지도로 바뀝니다. Trip Atlas와 같은 키(`trip-atlas:gmaps-key`)를 쓰므로 한쪽에서 넣으면 양쪽에 적용되고, 키가 거부되거나 로딩에 실패하면 OpenStreetMap으로 자동 대체합니다 (`pin/js/mapkit.js`).
- 구글 별점·리뷰 수는 Places API (New)로 화면에서 바로 불러옵니다(`pin/js/greviews.js`). 구글 약관상 별점은 저장하지 않고, 장소 ID만 기기에 저장합니다. 무료 범위(월 1,000건)를 넘지 않도록 구역 단위(12곳 이하)로만 불러오고, Google Cloud에 하루 한도(GetPlace 32건, SearchText 100건, 나머지 Places 기능 0건)를 걸어 두었습니다.
- 화면 캡처(390×844 @2x)는 `pin/screens/`에 있습니다.

## 실행

빌드 도구 없이 정적 파일만으로 동작합니다.

```bash
# 아무 정적 서버나 사용
python3 -m http.server 8080
# → http://localhost:8080
```

GitHub Pages: 저장소 Settings → Pages → Branch `main` / `(root)` 로 배포하면 그대로 열립니다.

## 데이터

- 모든 데이터는 브라우저 `localStorage`(`trip-atlas:v1`)와 올린 사진용 IndexedDB(`trip-atlas-images`)에만 저장됩니다. 서버가 없습니다.
- 기기 간 이동은 **백업·설정 → JSON 내보내기 / 불러오기**로 합니다. 백업 JSON을 이 저장소에 함께 커밋해 두는 것을 권합니다.
- 첫 실행 시 `src/data/seed-shizuoka.js`의 시즈오카 2026 예시 여행이 자동으로 들어갑니다.
